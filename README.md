# Minicurso de Pandas
## Minicurso criado e ministrado pelo PET Estatística da UFSCar, com público alvo são estudantes de graduação que desejam aperfeiçoar seus conhecimentos na área de dados.
## Neste repositório, abordamos as principais bibliotecas para se trabalhar com dados tabulares no python, como Numpy, Pandas e Matplotlib
Esse curso tem um nível introdutório, onde abordamos desde operações vetorias do Numpy até plotar os dados via matplotlib.

## Estrutura do repositório:
### Uma apresentação ```apresentacao.pdf```, contendo o resumo das funções do python.
### Um arquivo ```aula.ipynb``` que contém os scripts detalhados.
### Uma base de dados ```dataset.csv```, onde trabalharemos com os dados.
